# Blueprint

The starter includes the framework's version-matched guides and complete source
patterns so the first feature can use its installed JSKIT release directly.

Visitors see an accessible loading shell before JavaScript initializes, with a
Reload link and an explanation if application initialization fails.

A public web application with responsive navigation and a home page. Visitors
can use the application without signing in, check service availability, and
reach application settings. MySQL persistence is configured and migrations are
ready for the first application feature. No sign-up or login is required.
The standard CRUD framework and shared web screens are installed, so database
features start from existing APIs rather than library preparation.

Unit, client, browser and isolated database tests are ready to extend. Integration
tests and browser checks use separate databases and cannot select normal app data.

Pages open directly on useful content and actions without introductory title
blocks.
